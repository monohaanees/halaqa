حزمة تثبيت «سجل الحلقة» (PWA)
==============================
الملفات: index.html (التطبيق، بلا أي بيانات طلاب) · manifest.webmanifest · sw.js · ثلاث أيقونات.

أولاً: الرفع على GitHub Pages (مرة واحدة)
1) أنشئ حساباً مجانياً على github.com.
2) New repository ← الاسم halaqa ← اجعله Public ← Create repository.
3) Add file ← Upload files ← اسحب ملفات هذه الحزمة (الملفات نفسها لا المجلد) ← Commit changes.
4) Settings ← Pages ← Branch: main و Folder: /(root) ← Save.
5) بعد دقيقة أو دقيقتين يظهر رابطك: https://اسم-حسابك.github.io/halaqa/

ثانياً: التثبيت على أندرويد
1) افتح الرابط في Chrome وانتظر حتى يكتمل تحميل الصفحة.
2) القائمة ⋮ ← «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
3) افتح التطبيق من أيقونته. للتأكد من العمل بلا شبكة: شغّل وضع الطيران ثم افتحه.

ثالثاً: نقل بياناتك (مرة واحدة)
1) في النسخة الحالية: ⚙ ← «إنشاء ملف» ← انسخ النص ← «فحص الملف» وتأكد من الأعداد.
2) في التطبيق المثبّت: ⚙ ← الصق النص (أو اختر الملف) ← «فحص الملف» ← «استعادة».
3) قارن الأعداد مع القديمة. ثم اعمل في نسخة واحدة فقط ولا تسجّل في الاثنتين.

التحديث لاحقاً
استبدل index.html في المستودع (Add file ← Upload files)، ثم غيّر في أول سطر من sw.js الاسم halaqa-v1 إلى halaqa-v2 (ثم v3...) واحفظ. افتح التطبيق مرتين وأنت متصل.

حماية ملفاتك
- GitHub يحفظ تاريخ كل نسخة من الكود (History)، فتستطيع الرجوع لأي نسخة سابقة.
- بياناتك داخل هاتفك لا على GitHub. فاحتفظ بملف النسخة الاحتياطية خارج الهاتف (Drive) كل أسبوع.
- إذا فُرم الهاتف: ثبّت التطبيق من الرابط ثم استعد الملف.
- لا ترفع أبداً ملف نسخة احتياطية إلى GitHub لأن المستودع عام.
- فعّل التحقق بخطوتين على حساب GitHub واحفظ رموز الاسترداد.
